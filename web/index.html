Enterprise Control Tower Architecture

BharatFlow AI — Shipment Exception & Root-Cause Intelligence

An auditable, zero-cost, decision-support system built for Indian freight corridors. Combines deterministic statistical anomaly filters with autonomous ReAct tool-calling agent reasoning.

1. Statistics in the Hot Path

Exception detection uses rigorous statistical z-scores (dwell_zscore ≥ 2.0σ) against historical hub and transit baselines. No expensive or slow LLM is in the high-frequency telemetry loop—only flagged exceptions trigger agent investigation.

2. ReAct Agent Tool Dispatch

The agent dynamically queries specialized tools: live Open-Meteo weather API calls for the hub city, customs/e-way bill status lookups, and hub congestion telemetry before concluding.

3. Deterministic Confidence Scoring

Confidence and SLA breach risk percentages are computed by explicit, inspectable mathematical formulas in scoring.py rather than hallucinations from an LLM. The LLM provides plain-language reasoning, not arbitrary numbers.

4. Robust Zero-Crash Fallback

If API keys are absent, rate-limited, or network fails, the system executes an identical deterministic rule-based fallback. The mission-critical operations dashboard never crashes or blocks operator workflows.
